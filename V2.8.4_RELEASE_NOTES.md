# Migration Failure Agent v2.8.4

## Scope

v2.8.4 is an integration and evaluation hardening release. It does not add remediation execution.

### Kafka hardening

- MigrationFailed publisher now supports JSON argument, stdin, or an explicit error when no payload is supplied.
- Publisher validates the required event envelope before publishing.
- Kafka result includes source topic, partition and offset.
- Kafka result includes agent and policy versions.
- Existing event idempotency remains based on `event_id` through the SRE Tracker adapter.

### Evidence contract hardening

When required evidence is unavailable or returns NO_DATA, the investigation package now retains concrete evidence-collection requests. The result can therefore tell an SRE exactly which evidence is missing rather than only returning `COLLECT_MISSING_EVIDENCE`.

### Source-backed MTV corpus

Added `datasets/mtv_source_backed_corpus.yaml` containing 20 VMware-to-OpenShift Virtualization failure patterns backed by Red Hat documentation or Red Hat Customer Portal solution references. These are source-backed failure patterns, not claims about customer incidents or the user's organization.

Added `datasets/v284_evaluation_matrix.yaml` defining six evaluation conditions:

- NONE
- SRE_ONLY
- RHOKP_ONLY
- BOTH
- CONFLICT
- INSUFFICIENT

20 cases × 6 conditions = 120 planned case-condition runs.

### Honest coverage accounting

`scripts/run_v284_corpus_matrix.py` reports implemented versus NOT_IMPLEMENTED corpus cases. A corpus case is not considered implemented until deterministic classification, policy, skill, fixture and expected-output assertions exist.

## Validation performed

- `pytest -q`: 33 passed, 1 skipped
- Source corpus validator: 20/20 valid records
- Existing v2.8.3 CSI controller-error matrix: 4/4 PASS across memory modes

Expand deterministic support from the existing storage/network/CBT cases across the 20 source-backed corpus, adding one policy, skill, evidence fixture and golden expected result per failure pattern before claiming corpus-wide coverage.
