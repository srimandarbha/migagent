# v2.9.2

## Safety and contract fixes

- Removed the generic hard-coded retry facts `PVC_BOUND`, `VOLUME_AVAILABLE`, and `BACKEND_HEALTHY` from the safety gate.
- Added policy-driven `decision_readiness.retry.required_facts` for CSI, VMware CBT, destination NAD, ESXi connectivity, and unknown classifications.
- Added cross-classification regression tests that prove non-storage failures do not inherit storage retry blockers.
- Made `decision_readiness` the canonical five-action readiness contract: `CONTINUE_MONITOR`, `RETRY`, `FIX_FORWARD`, `ROLLBACK`, `ESCALATE`.
- Retained legacy `recovery` as a compatibility projection only.
- Added missing MTV-009 scenario classification registration.
- Updated README and package version to 2.9.2.

## Scope

This release remains read-only. It does not execute retry, remediation, rollback, EDA, AAP, or ServiceNow operations.
