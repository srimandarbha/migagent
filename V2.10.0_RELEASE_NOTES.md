# Migration Failure Agent v2.10.0

## Version-aware explicit LangGraph orchestration

### Added

- Explicit LangGraph workflow with separate nodes for case creation, classification, context, environment resolution, knowledge compatibility, evidence collection/evaluation, adaptive investigation, hypothesis evaluation, diagnosis, advisory LLM use, readiness, recommendation, persistence and finalization.
- `EnvironmentFingerprint` in `AgentState`.
- `environment.get_fingerprint` capability contract with deterministic event-metadata fallback for local testing.
- Deterministic RHOKP knowledge applicability resolver.
- Version-aware knowledge states: supported, background/unknown, mismatch, retired/conflicting.
- Version conflicts included in the investigation package.
- Version-awareness tests.

### Safety behavior

- LLM remains advisory only.
- Version mismatch never becomes a version-validated fix.
- Current evidence remains higher priority than historical memory or knowledge retrieval.
- No remediation, AAP, EDA or ServiceNow execution is enabled by this release.

### Verification

- 47 tests passed, 1 skipped in the local environment.
- LangGraph package import was not available in the execution sandbox, so the explicit graph topology was validated statically and node semantics were exercised through the deterministic fallback. Production execution uses LangGraph when the declared dependency is installed.
