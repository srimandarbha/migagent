# v2.10.2

## Deterministic compatibility + bounded LLM judge

- Added `judge_knowledge_applicability` as an explicit graph node.
- Invoked only when deterministic compatibility returns `NEEDS_VALIDATION`.
- Explicit `VERSION_MISMATCH`, `RETIRED`, `CONFLICTING`, and `NO_MATCH` decisions are hard rejects and never sent to the judge.
- Added structured judge verdicts: `LIKELY_APPLICABLE`, `LIKELY_NOT_APPLICABLE`, `INCONCLUSIVE`.
- Judge output is advisory provenance only and cannot become Evidence, Hypothesis, approval, execution, or a hard applicability override.
- Environment, failure signature and SRE historical context are supplied as structured input.
- Added model/provider/latency provenance.
