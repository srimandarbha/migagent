# v2.9.0 80-Scenario MTV Diagnostic Corpus

## What changed
- Expanded the MTV corpus from 20 to 80 source-grounded scenarios.
- Added source provenance for every scenario using current Red Hat MTV 2.12 documentation/release notes.
- Added deterministic evaluation-contract placeholders to every scenario.
- Expanded the matrix from 120 planned case/condition runs to 480.
- Preserved the six conditions: NONE, SRE_ONLY, RHOKP_ONLY, BOTH, CONFLICT, INSUFFICIENT.
- Added explicit gates: NOT_IMPLEMENTED is not PASS.

## Important
The corpus is source-grounded, not a claim that every listed condition has occurred in the user's organization. Synthetic fixtures must be marked `synthetic_test_record`.

## Current implementation
Only the previously implemented deterministic scenarios are executable today. The 80-case manifest is the benchmark contract. Do not manufacture 480 green tests by treating planned rows as passing.

## Target
80 scenarios × 6 conditions = 480 semantic evaluations.

## Categories
VMware/CBT, VMware connectivity, VDDK, Windows warm migration, plan validation, network/UDN/NAD, storage/CSI/CDI, disk/EXT4, virt-v2v/conversion, Linux/Windows guest compatibility, MTV platform/concurrency, compatibility and unknown-failure handling.
