# v2.11.0 Learning Lifecycle

## Why this exists

The Migration Failure Agent must handle failures that are absent from both SRE Tracker and RHOKP without treating the absence of knowledge as an agent error.

It must also avoid learning an incorrect fix merely because an operator previously tried an action.

## State model

```text
FIRST_SEEN
   |
   +--> current investigation
   |
   +--> no resolution recorded
          |
          +--> later occurrence -> RECURRING_UNRESOLVED

FIRST_SEEN
   |
   +--> SRE records verified recovery, but exact fix omitted
          |
          +--> RECURRING_RESOLVED
              resolution remains UNKNOWN

FIRST_SEEN
   |
   +--> verified resolution recorded
          |
          +--> CANDIDATE
                 |
                 +--> human validation
                        |
                        +--> KNOWN_ISSUE
```

## Recurrence states

- `FIRST_SEEN`: no matching previous failure signature.
- `RECURRING_UNKNOWN`: matching cases exist, but no validated resolution is available.
- `RECURRING_UNRESOLVED`: matching cases exist and previous occurrences did not reach a verified resolution.
- `RECURRING_RESOLVED`: previous occurrences recovered, but no validated reusable solution exists.
- `KNOWN_ISSUE`: a validated learning candidate exists for the matching signature.

## Memory availability states

- `NO_DATA`: the SRE Tracker query succeeded and found nothing.
- `UNAVAILABLE`: the SRE Tracker could not be queried.
- `DISABLED`: recurrence lookup was intentionally disabled for the run.
- `ERROR`: the Tracker query failed unexpectedly.

Only `NO_DATA` supports the conclusion that there is no known historical record in that source.

## Learning promotion gates

```text
Observed action
     |
     v
Recorded resolution
     |
     v
Outcome = RESOLVED
     |
     v
Verification = PASSED
     |
     v
CANDIDATE
     |
     v
Human validation
     |
     v
VALIDATED / KNOWN_ISSUE
```

A successful migration without a recorded resolution is not sufficient to learn the fix.

An action performed repeatedly is not sufficient to learn the fix.

A verified candidate is not promoted to reusable knowledge without explicit validation.

## Current evidence precedence

```text
CURRENT_EVIDENCE
    > SRE_HISTORY
    > RHOKP_KNOWLEDGE
    > LLM_ADVISORY
```

Historical memory can enrich investigation but cannot override contradictory current evidence.

## Read-only boundary

The initial Migration Failure Agent remains read-only. `LearningLifecycle.record_resolution()` records an externally performed SRE action/outcome. It does not execute remediation.
