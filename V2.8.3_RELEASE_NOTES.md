# Migration Failure Agent v2.8.3

## Scope
Semantic hardening of the diagnostic output contract. No remediation execution was added.

## Changes
- Added structured `diagnosis_basis` with supporting evidence, contradicting evidence, excluded mechanisms, and memory context.
- Added explicit `root_cause`, kept separate from diagnosis mechanism.
- Added `investigation_package` with actionable next investigations, capability contracts, purposes, do-not-do controls, and success conditions.
- Added structured `decision_readiness` for monitor/retry/rollback/remediation.
- Kept legacy `recovery` output for backward compatibility only.
- Added explicit memory conflict reporting while preserving current-evidence precedence.
- Preserved unknown-vs-insufficient-evidence distinction.
- Updated simulator output and package version to 2.8.3.
