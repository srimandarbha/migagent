# Migration Failure Agent 2.10.1

## Deterministic knowledge applicability

This release separates semantic knowledge retrieval from deterministic applicability.

- RAG/LLM identifies candidate knowledge; it does not decide version applicability.
- Structured failure/error codes are checked deterministically against knowledge signatures.
- MTV/OCV/OCP/VMware constraints use semantic version parsing, including patch versions.
- A lower-version solution may apply to a higher version only when its applicability metadata explicitly permits the higher version, such as `min: 2.8`.
- A higher-version solution is rejected for a lower installed version when its minimum version is above the installed version.
- Missing applicability metadata is `VERSION_UNKNOWN` and requires validation; it is never silently promoted to a version-validated fix.
- Version mismatch and error-signature mismatch are excluded from eligible recommendations.

## Safety boundary

The LLM may extract or summarize knowledge, but the deterministic compatibility engine remains the authority for error matching and version applicability.
